Non-Locking Calibre Database Reader Active

NovelTrax uses SQLite's mode=ro&immutable=1 protocol. SQLite bypasses all filesystem lock requests on network shares and host filesystems. This guarantees that your host Calibre application, Calibre-Web, or network clients will never experience database write locks or blocking.

TorBox is a debrid cloud service: NovelTrax hands it a Nyaa magnet or .torrent URL, TorBox fetches it on its servers, and NovelTrax downloads the finished files into the local downloads folder. Maintenance & Debug Tools

Use these tools to clear cached metadata, purge unreviewed discovery series to re-scrape cleanly, or empty the local thumbnail storage.

Clear Descriptions

Resets all stored novel descriptions/synopses across releases and series so they can be re-fetched fresh from feeds or on-demand.

Clear Discovered Series

Purges unreviewed series from the Discovery page. Active wishlist requests and Calibre library tracking remain completely untouched.

Clear Thumbnails

Deletes all cached image files in the container's storage cache. Images will be re-downloaded safely upon browsing.

Purge PDF Releases

Permanently deletes any PDF releases and deduplicates series. NovelTrax strictly monitors digital novel EPUBs.

Clear Metadata Cache

Clears the cached AniList/Kitsu synopsis, cover and title metadata. Data is re-fetched on demand; releases, requests and settings are untouched.
